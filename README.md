An alien tourist reviews Earth like a disappointed traveller: one star for the arrivals desk, which kept them queuing for forty minutes only to declare their home planet does not exist, and five stars for the food, because the sweet, cardamom-spiced mango lassi in their hand tasted like a full refund. Running `main.ts` writes the one-sentence review to `/output/entry.txt`.
